# Nordlys

**Plattformen for å dele kritisk informasjon i kraftsektoren.**

## Dette repoet
Inngangen til nettsiden om Nordlys på https://www.n0rdlys.no, publisert med GitHub Pages. Siden brukes foreløpig internt i forprosjektet og krever passkode. Selve innholdet ligger ikke i dette repoet.

- `index.html`: siden der man skriver passkoden
- `styringsgruppe/`: innlogging for styringsgruppen
- `assets/`: logo, ikon, partnerlogoer og fonter (Manrope og Bricolage Grotesque, SIL Open Font License 1.1)

*Sammen lyser vi opp*
